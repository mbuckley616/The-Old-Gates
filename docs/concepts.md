Found on the way: the conversation's hint reads "1–4 to choose" whatever the number of topics (`#dlg-hint`, static; Sorcha has seven); the game frame is fixed at 600 px tall (`#g{height:600px}`), so a 720 px window leaves 120 px of empty page under it.
