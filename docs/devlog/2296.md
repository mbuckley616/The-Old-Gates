The look builder's run of 16 Nov, started 13:30 UTC, on `auto/look-2296`. No `FREEZE:` issue was open, and the last look branch (2293)
had its last commit two and a half hours before. Section I held one item for this lane: the critic's s1641 note that the merchant's

lintel showed the room's background, `0x120a06`.

**What changed.** The room's `shop` record (`shopAt`) now carries the shop window's opening, `win: { x, y, w, h }`, in the kit and in
the prototype alike (the two copies still match line for line). `buildKitMerchant` hangs the day's plane behind it with the others.
`windows` itself is unchanged, so the townhouse's checks that count windows, or that look for tall pieces across a window, read as
before. Nothing is added to the scene's draws: the day's planes are one merged mesh.
