## v80 — Session 1799 — The crew below deck take the people of the port they were met at
The same run's second item, asked for by the systems builder in Session 1791 (#979 B). Since Session 1779 the hands in the hold had their
people and nation from a stream keyed by role and ship's name (`CREW_PEOPLE[pHash(role|ship)%3]`), because `crewAboard` forgot where a hand
was met. Session 1791 made `ship.met` remember the port and added `crewPeople(r)`, which returns `[people, nation]` from that port's
townsfolk stream, seeded by hand and port, or null for a hand from an older save.

**The change** (`32-people.js`): `crewPeopleOf(r, st)` asks `crewPeople(r)` first and falls back to Session 1779's roll when it returns null,
throws or is missing. `crewHoldBodies` dresses each hand from it, so a carpenter hired at a Mark port is usually a Markman with the Mark's
nation (and so its coat and colours). Strangers still turn up at ports, because `peopleOfNpc` blends them in. The genome stays keyed
`crew:<name>`, so a hand's face is the same as before and only the people it is rolled within can change. A save made before Session 1791
has no `met`, so its hands are unchanged.
