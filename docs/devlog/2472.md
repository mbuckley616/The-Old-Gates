## v80 — Session 2472 — a drawn blade leaves its scabbard on, empty
The same run as Session 2471, on `auto/bodies-2471`. It takes the note that Session 2471 left: a drawn blade left no scabbard on the
body. The worn group (the scabbard, the frog, the baldric) was built only while the weapon was sheathed, so it went when the draw ended
(since S2456; S2462 added *drawn, the strap is gone with the scabbard*). A scabbard belongs to the belt it hangs from, not to the blade
in it. Now the draw ends with the hand holding the blade and the empty scabbard still on.

**What changed** (`js/54-thirdperson.js`, the new look only):
- `tpScabOn(W)` is the rule for which weapons go in a scabbard: a dagger, sword, cutlass, longsword or claymore (`tpSheath`'s own
  blades).
- When such a blade is in the hand, `tpBuild` now also builds the worn group from a hidden copy (`R.sheathW`, `R.scabOnly`) and hides
  its blade. A mace, an axe, a spear, a staff and a bow build nothing, as before.
- `R.sheathed` now says whether the weapon is sheathed. `R.sheathW` is set in both states, so it no longer does.
- The draw (S2471) takes the blade out of this new body's own empty group. The old group is dropped when the rig is rebuilt, not 0.56 s
  later, so nothing is left to remove at the end of the draw.
- The sheathe is unchanged: it builds the full group and the blade is shown in it at 0.3 s.
- No new geometry kinds. A drawn blade now carries its scabbard's triangles too: about 1,500 for the sword, and the frog's 132 or the
  baldric's 1,024. The scabbard's shape is cached by kit and colour (`TP_SCAB`). The frog and the baldric are built per body, so a
  rebuild while a claymore is drawn now builds a baldric. Sheathing measured 19 ms for the sword and 60 ms for the claymore.
