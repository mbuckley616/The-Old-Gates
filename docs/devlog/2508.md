## v80 — Session 2508 — a bedroll, a tent and a sword's make kept through a save
The systems builder's run of 22 Nov (early), on `auto/systems-2508` from origin/main at s1835. No `FREEZE:` issue was open, no pull request
was open, and the last systems branch (2505, #1872) had landed. Section I holds nothing for the systems builder, `docs/quest_review.md`'s run 53
is clean, and every answered systems decision is built; the one still owed, rare materials' fifth session, waits on #1861 (deep pearls). So
this session is a bug hunt in the lane's own files.

**What was wrong.** `_serItem` (`js/70-saves.js`) keeps an item's fields from a list, and anything not on it is dropped by a save. S2494 found
fifteen lost fields with a probe of the flags the code sets. A probe that walks every item the game defines (each top-level constant, three
deep, every object with a name, an icon and a type: 217 of them in the probe, 283 in the suite once a town's stock has loaded, plus
the bedroll and sword makers) and puts each through `_serItem` found
three more still lost:
- `roll`, every bedroll's kind (S2090). After a reload a Blanket Roll, a Wool Bedroll or an island's roll was a plain thing: E no longer laid
  it (`useItem` reads `it.roll || it.tent`), the night's rest no longer counted it, and the Kit tab no longer listed it.
- `tent` (S2090). `hasTent()` read false after a reload, so a tent bought for 45 gold stopped pitching over the roll.
- `swordMake` (S2117). A sword's make, the kit's blade by island (the arming sword, the Norse sword, the takouba, the falchion, the flyssa,
  the nimcha), was lost, so in third person a Markish or Aurennais sword drew as the plain sword after a reload. The island (`make`) was kept.

This corrects S2090 and S2117, which added the fields, and S2494, whose probe did not reach them.

The probe also lists six fields the list leaves off on purpose, and they stay off: `enchant` (saved by its id), `reqAttr` and `reqVal`
(rebuilt from the material on every load, `_migrateItemValueAndReq`), `potionId` (nothing reads it), and the creator's starter-only `buildVia`
and `grantsAmmo`.

**What changed.** The three fields join the list. A field is only copied when an item has it, so nothing else changes. No new `worldState` key.
