renderer's pixel ratio, the sun's shadow box, `HBODY`, `HC_BODY`, `HOUSE_LOD`, `HERB_LOD`) and then calls the land's `landQuality()`
(the shadow map and the clouds). No builder's file changes how it reads its own distances. `landQ()` keeps its name and returns the
row, so the land's code is unchanged, and `LAND_Q` is gone. The settings row and *Back to defaults* call `qualityApply`. The world's
first frame calls it too, through `landPost`, so a level saved in this browser holds from the start. The point lights are compiled
into every lit shader, so `buildLights` reads `lights` once, at the start: a change takes effect at the next start, as the sheet says.
