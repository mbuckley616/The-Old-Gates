**What was wrong.** Three suites have lost their browser mid-run: `budget` (FLAKY at s1967, S2646), `budgetfield` under parallel
boots (the look builder, S2632 and S2635) and `f4people` on #2011 (45562666614, red on both tries). Each says only *Target page,
context or browser has been closed*. The harness listened for neither the page's `crash` nor the browser's `disconnected`, and
Chromium's stderr went nowhere, so a renderer crash, a kill by the kernel and a clean exit all read the same.

**What changed** (`tests/lib/game.mjs`, the harness, so this is a pipeline PR):
- `browserTail()` turns on Playwright's `pw:browser` debug channel, which carries Chromium's stderr line by line and its exit line
  (`<process did exit: exitCode=…, signal=…>`). Its lines are kept in memory, the last 40 (`BROWSER_TAIL`), not written to stderr.
  Launch's `logger` option never sees that channel, so the hook is on the `debug` instance in `playwright-core/lib/utilsBundle`; if a
  later Playwright moves it the tail is empty and nothing else changes. The page's console lines, WebGL's stall notes and the
  container's dbus noise are left out of the tail. `DEBUG=pw:browser` still echoes everything to stderr as before.
- `boot` notes the browser's pid from its `<launched>` line. On `page.on('crash')` it prints `lost: the page crashed (the renderer
  died) at N s` and that browser's tail; on `browser.on('disconnected')` before the suite closed it, `lost: the browser disconnected`
  and the tail, then the exit line when Chromium logs it a moment later; on the page's `close`, `lost: the page closed`. `g.close()`
  sets a flag first, so a suite's own close prints nothing. No suite calls `browser.close()` directly (0 of 648).
- Nothing changes on a run where the browser lives: no line is printed, and no check reads any of it.

### Verified (headless Chromium)

  crashing … Received signal 11 SEGV_MAPERR* and its stack; a browser killed with SIGKILL printed *the page closed*, *the browser
  disconnected* and `<process did exit: exitCode=null, signal=SIGKILL>`; a third boot closed by `g.close()` printed nothing.
- `looknew` 1/1 and `saves` 1/1, `--no-retry`: no `lost:` line and no `pw:browser` line in either log.
