  so a second chance never changes another's kind.

  only the first chance by the road (`waysideFirst`), so a new camp by a road cannot push a hut. A second chance by the road keeps 150 m from
  the cell's first chance off it (`offroadFirst`), as the hut would have kept from it. The order is acyclic: first by the road, first off it,
  second by the road, second off it.
- A second-chance place carries `second: true`. Its id is the cell's (`wayside_i_j`, `offroad_i_j`), as a cell holds one of each at most.
