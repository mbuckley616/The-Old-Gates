## v80 — Session 1914 — the Bellthroat's sac swells as it calls (L3; OG-040)
The run's first item. Section I holds nothing new for the bodies builder; Pádraig's cloak is still watched. Session 1913 (systems) gave the
Bellthroat its call at dusk, three booms and their echo, and Session 1907's run left the sac swelling at dusk owed. The catalogue's row
is the spec: *a red frog with a huge violet throat sac whose call echoes across valleys at dusk*. Until now the game's frog called with a
still throat. The kit pulses the sac with the hop's phase, and at rest that phase does not move, so the sac sat at its rest size.

**What changed** (`34-creatures.js`, the bodies builder's file only).
- `hcSwimPose` sees a call when the creature's `e._calls` count goes up (Session 1913's `bellthroatCall` already keeps it). Nothing in
  `42-zone-enemies.js` changed. The first time it sees a body, it takes the count without a swell, so a body built mid-dusk does not
  swell for a call it never heard.
- `hcBellSac(t)` and `BELL_SAC` give the swell over the call, matched to `sndBellthroat`'s timing. The sac fills to +0.55 of its radius in
  0.08 s and is held there. On each of the three booms (0.32 s apart, 0.26 s long) it swells a further +0.6 on a half sine. It empties over
  0.3 s after the third boom, about 1.2 s in all. The echo is the valley's, so the sac stays empty for it.
- The swell multiplies the kit's own pulse, so a frog hopping as it calls still pulses under it. It is read on `performance.now()`, so a
  dropped frame changes nothing. Only the near body has a sac to move. The middle level is baked, as every creature's is.

### Needs eyes
- How big the sac goes. At 2.15 times its radius it is about the frog's own head and chest. That reads as "huge" in the picture, and it
  is the one number to turn down (`BELL_SAC.boom`) if it looks like a balloon in play.
- Whether the swell lines up with the sound by ear. Both start on the same tick, and the booms are on `setTimeout`, so a busy frame can
  push the sound a few hundredths of a second behind the sac.
