  the ground stays at the 0.66 the builder page shows. A plain fitting stays `metal`.

  piece per group, each to its own material, and `wpnBuild`'s merge carries the uvs for the `fit:` buckets (and only those).
- `hbTellTris` counts a `fit:` material as metal, so the blow's tell reads the fittings as it did before.
