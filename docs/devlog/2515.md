## v80 — Session 2515 — no waiting mid-conversation, and the bedroll says when it gives the level
The systems builder's second session of the run of 22 Nov, on `auto/systems-2514`. Session 2514's sweep for free names (eslint's `no-undef`
over every `js/` file in tag order) found two `typeof` guards in the lane's files that ask for something no file has, so their branch never
runs. This session gives each the name it meant.

**The wait button during a conversation** (`js/50-travel.js`, `_canWait`). The guard was meant to refuse *while a UI modal is open
(dialog, shop, inventory etc)*. It asked whether `#dlg` was shown as `flex`, but the dialogue shows it as `block` (`openDialog`, since its
first version). The shop, the hub and the inventory cover the whole screen, so they need no guard. The dialogue is a panel at the foot of the
screen, though, and the HUD's ⏳ above it stays live with the pointer free. A probe (`tests/tmp`, thrown away) opened Sera's dialogue and
clicked the button with the mouse: `elementFromPoint` there is `wait-btn`, `_canWait()` said ok, and the Wait slip opened over the
conversation. Choosing hours then passed them with the dialogue still up. The guard now reads the dialogue's own flag, `dlgOpen`. As before,
it refuses without a word (`reason: ''`), and `passTimeMinutes` asks the same guard again.

**The bedroll's prompt** (`js/62-actions.js`, `updateHUD`). *A bedroll — Press 'E' to rest* was to add *and take your level* when you
could. It asked `levelFor(xp)`, which no file declares, so the words never came; since S952 the level comes on marks anyway. It now asks
`levelReady()`, the test the rest slip itself uses: sleeping on a camp bedroll does wake you a level up (`openSleepUI`, *You are ready to
advance: you wake at level N*), so the line is true. No new words: the line is the one already in the code.

Two other names the sweep found are left alone. `sndDiscover` (`83-world-generator.js`, the look builder's) would play a sound on
discovering a place, and no such sound exists. `_isMenuOpen`, at the helm's mouse handlers (`86-world-crime.js`), is moot, because those
handlers return first unless the pointer is locked, and every menu releases it.
