## v80 — Session 1590 — Bodies in a gate no longer wait for the town's jobs
*Renumbered from Session 1586 (Session 1590): the systems builder's Sessions 1586–1588 landed first and left #897 in conflict on the devlog, so #897 is closed and its three sessions are carried here unchanged but for their numbers.*
Found on the way to Session 1591. No freeze was open, the last bodies run had landed (#892), and section I holds nothing for this lane.

**What was wrong.** Both builders, the people's (`hbTick`, `32-people.js`) and the creature kit's (`hcTick`, `34-creatures.js`), hold a
body back while the world's job queue (`JOBS`, `81-world-cells.js`) has work in it, so that a body is never built in a frame that is
also loading a cell. Only the open world runs that queue (`WORLD.tick` returns at once anywhere else). Rooms were already excused
(`isInterior()`), but gates were not. Enter a gate from a town with a few jobs still queued, and the queue never drains, so no body is
ever built there. In an undead gate entered this way, 14 kit rigs (Skeletons and their kin) sat on their old bodies with three town
jobs queued (`'()=>{t._queued=false;…'`). On a run where the queue happened to be empty they built.

**What changed.** The queue holds a body back only where it runs: `activeZoneId==='world'` and not a room. This is one condition on the
same line in both files. Nothing else moved: in the open world the rule is as it was.

### Verified (headless Chromium, new look)
- A throwaway check in an undead gate (seed 11): with the change, the gate's kit bodies build one at a time over the following frames,
  as in the open world. Before it, 0 of 14 built while the queue held three jobs.
- `f4slimes` (Session 1591) builds its slime with a job pushed onto the queue for the whole build: 7 jobs queued, built in 6 ticks.
- `f4bones`, `f4people`, `f4sharks`, `slimes`, `slimesplit`: see Session 1591's entry, run once for both.

### Needs eyes
- None beyond play. In a gate entered from a town, the foes nearest you should now change to their kit bodies within a few seconds,
  instead of staying on the old ones.
