line:

- if there is none, it takes the people of the nation the door stands in (`nationOf(...cellOf(doorX, doorZ))`);
- any other value reads as gatelander.

`knockDoor` uses it for both answers, and `openShop` uses it for the refusal. The colours and the narrator's lines are unchanged. The rule
is unchanged too: the knock still answers by the town's favour and the hour, and the refusal still comes from `refusesTrade`.
