## v80 — Session 1218 — a bought ship is never the *Kestrel* (the quest writer's Finding 32)
The quest review's run 22 (19 Oct) found that the player's ship can be named for the villain's courier's: the *Kestrel* is
Oswy Blackhand's ship, the courier step's marker in Act II, and it was one of the ten names `spawnShip` draws from
`SHIP_NAMES` (`84-world-interiors.js`) when a ship is bought or granted. A player sailing a *Kestrel* of their own could not
tell the marker, the map or the log's *Kestrel* from their own. Applied exactly as written, without a decision (register fixes,
the systems builder's first item): `'Kestrel'` becomes `'Bad Penny'`, and nothing else changes. A ship saved under the old name
keeps it, since `spawnShip` reads `worldState.ship.name` first.

The file is the look builder's by the code map; the change is one string in a name list, the kind the review asks the builders
to apply as written.

### Verified (headless Chromium)

names and never *Kestrel*; a ship saved as the *Kestrel* came back the *Kestrel*. `saltwater` (the shipwright's sale) 15/15.
