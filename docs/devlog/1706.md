## v80 — Session 1706 — half the deer are hinds
Renumbered from 1705 at the merge: QA's run landed a Session 1705 (`f10hands`) on main first.

The run's second item, from Session 1704's *Needs eyes*. The kit's `deer` plan is the Elderstag's body with shorter antlers, so every deer in a
field would have been a stag. A herd in the fields (OG-014, and the "deer (2 to 4) in woods and fields" of #984's A) is mostly hinds.

**The change** (`34-creatures.js`).
- `HC_KINDS` gains **Hind**: the kit's `deer` with `own` and `bare`. In `hcPlan`, `bare` makes its own plan (`game:Hind`), the deer's plan with the
  head's `antlers` taken off. The plan is otherwise the same, with the same palette and the same hoof bend.
- `buildAnimal('Deer', key)` makes a hind when the key's hash is odd. The hash is `animalHash`, a new top-level name: FNV-1a over the key, the same
  on either look, because `HC.hashKey` exists only on the new one. A hind is built at nine tenths of the stag's size and carries
  `rig.hcKind='Hind'`, so the kit dresses it as the Hind while the driver stays the Deer's. Its genome is still keyed `wild:<key>`. Without a key,
  a deer is always a stag.
